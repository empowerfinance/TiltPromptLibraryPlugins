# Prompt Library (VS Code)

A VS Code extension providing a sidebar view for managing Shared/Private prompt libraries. This repo follows the plan in `VSCode/docs/BABY_STEPS_PLAN.md`.

Status: Phase 1 scaffolding created (view + hello command). Store skeleton present.

Getting started
1. Install deps: `npm install` (in `VSCode/`) — not run by the agent.
2. Build: `npm run compile`.
3. Press F5 to launch the Extension Development Host.
